# HSI16 P1–P99 全量新成员（2026-09-19）

## 目的

当前八模型融合已接近饱和，继续加入同预处理、同 seed 的重复模型很难提供独立误差。本实验只改变一个训练变量：把 16 波段、逐图共享的 uint8 缩放范围从 P0.5–P99.5 改为 P1–P99；模型、seed、训练轮数、全量训练范围和自动 batch 降级策略保持不变。

- Notebook：`zephyrpong/hsi-yolo26m-p010-990-full`（私有）
- 运行名：`kaggle_full_yolo26m_hsi16_p010_990_e30`
- 模型：YOLO26m，官方 `yolo26m.pt`
- 输入：16 波段 NPY，逐图所有波段共享 P1–P99 缩放
- 数据：全部 3000 张标注图训练，不做伪标签
- `imgsz=1024`，`epochs=30`，`seed=2026`
- 尝试顺序：`batch/workers = 8/2, 6/2, 4/2, 4/0`
- 训练后生成 7 尺度 `832/896/960/1024/1088/1152/1216` 单模型 CSV
- Notebook 不执行 Kaggle Competition Submit
