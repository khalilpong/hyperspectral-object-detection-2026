# 单 checkpoint 尺度来源消融（2026-09-22）

## 目的与边界

当前合规最佳推理使用同一个 YOLO26m checkpoint 的七个输入尺度
`832/896/960/1024/1088/1152/1216`。此前已经扫过统一的 fusion IoU、
support gain 与若干坐标估计方法，但没有证据表明当前 YOLO26m 做过
leave-one-scale-out、中心尺度子集或逐尺度固定权重。

本实验只重放 fixed-val 缓存 `artifacts/ensemble_cache/m.pkl`：

- 一个 checkpoint，600 张固定验证图；
- 不加载模型、不开 GPU、不生成 test CSV、不提交；
- 固定 `fusion_iou=0.74`、`support_gain=0.125`、`max_det=300`；
- control 为全部七尺度、统一权重；
- 接受门禁为全集 mAP50-95 至少 `+0.001`、三折最差不低于
  `-0.0005`，且至少两折为正。

运行脚本：`scripts/eval_single_model_scale_sources.py`。

## 预注册候选与结果

control 精确复现 `0.70570818`。所有 11 个候选均未过门禁：

| 候选 | mAP50-95 | 相对 control |
|---|---:|---:|
| drop 832 | 0.70514105 | -0.00056713 |
| drop 896 | 0.70390647 | -0.00180171 |
| drop 960 | 0.70402660 | -0.00168158 |
| drop 1024 | 0.70463741 | -0.00107078 |
| drop 1088 | 0.70473497 | -0.00097321 |
| drop 1152 | 0.70482071 | -0.00088747 |
| **drop 1216（候选中最高）** | **0.70526277** | **-0.00044541** |
| center 3: 960/1024/1088 | 0.70393026 | -0.00177792 |
| center 5: 896–1152 | 0.70478820 | -0.00091999 |
| 中心尺度偏重固定权重 | 0.69621899 | -0.00948919 |
| 两端尺度偏重固定权重 | 0.69533164 | -0.01037654 |

逐尺度权重会同时改变聚类顺序、坐标平均和最终 top-300 排序；两组事先固定的
对称模板都明显恶化，因此不继续从这 600 张验证集拟合七个自由权重。七个
leave-one-out 结果全部为负，也没有“明显坏尺度”可删除。

## 结论

保留全部七尺度及统一来源权重。该方向已否决，不转移到 full-data checkpoint，
不生成正式候选，不消耗 Kaggle Submit。当前训练主线仍是分别等待并门禁
`dfl=2.0` 与 `dfl=2.5` 的单模型 fixed-split 作业。
