# HSI16 推理超参优化与 Kaggle 提交记录

## 实验背景与决策依据

1. **YOLO26m 伪 RGB 60 轮基线完结**：
   - 任务 \blation_m1024_b3_b5-8-13_e60_clean_r1\ 平稳完成全部 60 轮训练。
   - 留出集最佳 mAP@0.50:0.95 为 **0.69811**（第 50 轮），第 60 轮收敛于 0.69728。
   - 该指标仍低于 16 通道 HSI YOLO26s 的留出集表现（0.69817 / 0.69873），验证了伪 RGB 在特征维度上的天然劣势（丢失 13 个光谱波段）。因此停止后续无收益的伪 RGB 冗余实验，聚焦于 HSI16。

2. **留出集后处理网格搜索**：
   - 在固定的 2400/600 留出集（uns/ablation_s1024_b4_hsi16_shared_p005_995_r1/weights/best.pt\）上，系统评测了置信度阈值、NMS IoU 阈值、最大目标数与输入分辨率：
     - **置信度阈值**：\conf=0.0001\ (0.69873) > \conf=0.0005\ (0.69862) > \conf=0.001\ (0.69859) > \conf=0.01\ (0.69792)。极低置信度完整保留了低置信度真阳性 recall。
     - **NMS IoU 阈值**：\iou=0.60\ (0.69834) < \iou=0.70\ (0.69873) < \iou=0.75\ (0.69894) < \iou=0.80\ (**0.69913**)。IoU=0.80 将留出集 mAP@0.50:0.95 提升了 +0.00040。
     - **Max Detections**：\max_det=300\ (0.69913) 与 \max_det=500\ (0.69914) 性能完全一致，保持 300 最佳。
     - **分辨率**：\imgsz=1024\ (0.69913) 明显优于 \imgsz=1088\ (0.69341)。
