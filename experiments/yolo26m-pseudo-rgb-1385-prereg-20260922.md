# YOLO26m pseudo-RGB `[13,8,5]` fixed-split preregistration

Date: 2026-09-22 (Asia/Singapore)

Status: local private Kernel package generated and tested; **not uploaded and not running**.

## Question

Does assigning selected bands to pretrained RGB input channels as `[13,8,5]`, instead of the previously tested `[5,8,13]`, improve a single YOLO26m checkpoint on the unchanged fixed 2,400/600 split?

This is an input-channel-order test, not a reproduction of the public `hyperspectral-baseline` Notebook. That Notebook's displayed `0.7394` is invalid as independent validation evidence because its recursive glob duplicates every source path and causes 788 of 844 effective validation images to also occur in train. See `latest-public-strategy-research-20260922.md`.

## Fixed contract

- architecture/model: one YOLO26m checkpoint from `yolo26m.pt`;
- data: `pseudo_rgb:13,8,5`, generated by the project's existing `prepare_pseudo_rgb.py` path;
- split: exact existing seed-2026 manifest, 2,400 train / 600 val; the remote runner must compare every manifest row and fail on drift;
- training: 30 epochs, image size 1024, seed 2026, attempts `8:2,6:2,4:2,4:0`;
- unchanged augmentation/loss values: `degrees=0`, `scale=0.5`, `dfl=1.5`, `cls_pw=0`;
- no multi-scale inference during the fixed gate;
- no second checkpoint, fusion, pseudo-labeling, public random split, min-max/JPEG reproduction, or Competition Submit.

The exact generated private slug is `zephyrpong/hsi-yolo26m-prgb1385-ablation`; the local package is `kaggle_remote/kernel_ablation_prgb1385`.

## Comparators and gate

- closest single-variable comparator: YOLO26m pseudo-RGB `[5,8,13]`, fixed best mAP50-95 `0.69726`;
- ordinary HSI16 YOLO26m fixed result: `0.70143`;
- full-data admission gate: `0.70443`.

Only a full fixed-validation result at or above `0.70443`, with 30 epochs, exact manifest, successful return code, fresh-reload checkpoint, and valid 1,000-image test inference, may advance to a full-data run. A lower result is rejected without full-data training or submission even if it beats the older pseudo-RGB comparator.

## Scheduling decision

Do not push this package while the independent RT-DETR-L HSI16 and YOLO26m `degrees=5` fixed jobs are both running. Reconsider it only after those results are audited and only if remaining Kaggle GPU quota and deadline allow. This avoids consuming a third concurrent slot based on a leaked public metric while preserving a ready, isolated fallback.
